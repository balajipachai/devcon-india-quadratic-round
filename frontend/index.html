Projects and how each match was worked out

How the match works
  1. Each person's total to a project counts once, however many times they gave.
  2. Take the square root of each person's total, add the roots up, then square the sum. That is the project's score.
  3. The part of the score above what people actually gave is the breadth bonus. One big backer adds nothing to it, many small backers add a lot.
  4. The matching pool is shared out in proportion to each project's breadth bonus.
